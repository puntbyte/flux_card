# flux_card_widgetbook

A Widgetbook catalog for `flux_card`.

## Run

From this folder:

```bash
flutter pub get
flutter run -d chrome
```

## What is covered

- `FluxCard` layout modes: column, row, stack, responsive
- `FluxBackground`: color, gradient, image, custom decoration
- `FluxHeader`: leading, subtitle, trailing, long text
- `FluxFooter`: horizontal, wrapped, stacked actions
- `FluxOverlay`: chips and badges
- `FluxCardThemeData`: standard, compact, elevated, custom
- Real-world compositions for product, travel, and blog cards
